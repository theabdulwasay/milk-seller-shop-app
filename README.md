
# 🥛 Milk Seller Shop

A responsive, lightweight **Flutter** application designed for managing daily operations in a local milk shop. Track inventory, record sales, manage customer accounts, and view daily reports—all from a single intuitive dashboard.

---

## ✨ Features

- 📊 **Dashboard:** Real-time overview of daily sales, low-stock alerts, and key metrics.
- 🛒 **Sales Management:** Quickly log new transactions and track recent sales.
- 📦 **Inventory Tracking:** Monitor stock levels and update product inventory seamlessly.
- 👥 **Customer Management:** Keep track of regular buyers, outstanding balances, and purchase history.
- 📈 **Sales Reports:** Simple summaries to help analyze shop performance over time.

---

## 🛠 Tech Stack & Architecture

- **Frontend:** [Flutter](https://flutter.dev/) (Dart)
- **Target Platforms:** Android, iOS, Web, and Desktop
- **State & Data:** In-Memory sample state (Zero third-party runtime dependencies)

## 🚀 Getting Started

### Prerequisites

Ensure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed on your machine.

```bash
flutter --version

```

### Installation & Setup

1. **Clone the repository:**
```bash
git clone [https://github.com/theabdulwasay/milk-seller-shop-app.git](https://github.com/theabdulwasay/milk-seller-shop-app.git)
cd milk-seller-shop-app

```


2. **Get dependencies:**
```bash
flutter pub get

```


3. **Run the application:**
```bash
flutter run

```


4. **Run widget tests:**
```bash
flutter test

```



> **Note:** Currently, sales, inventory adjustments, and customer additions are retained in-memory for the current session. For persistent data across app restarts, connect a database backend (e.g., SQLite, Firebase, or a Dart/Node.js REST API).
