# Milk Seller Shop

A responsive Flutter app for managing a small milk shop. It includes a
dashboard, sales, inventory, customers, and a simple sales report. The app uses
sample data stored in memory and has no third-party runtime dependencies.

## Run the app

Install the Flutter SDK, then run these commands from this folder:

```powershell
flutter pub get
flutter run
```

Run the widget test with:

```powershell
flutter test
```

Sales, inventory changes, and new customers are kept in memory for the current
app session. Connect a database if the shop needs persistent records.
